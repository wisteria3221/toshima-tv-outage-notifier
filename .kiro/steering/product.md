# プロダクト概要

としまテレビの障害情報ページ (https://www.toshima.co.jp/trouble/) を定期的に監視し、障害の新規発生やステータス変更を検知してX（Twitter）へ通知する自動監視システム。GitHub Actions上で30分ごとに無人実行される。

主な利用者は、としまテレビのインターネット・テレビサービス利用者、および障害情報をフォローしたい地域住民。

## コア機能

- **障害情報の取得**: 公式障害情報ページをスクレイピングし、障害の一覧（ID・日付・ステータス・タイトル・地域）を構造化データとして抽出する
- **差分検知**: 前回実行時の保存状態と比較し、「新規障害」と「ステータス変更」のみを変更として検出する
- **重複抑止つき通知**: 同一ステータスを二重通知しないよう、通知済みステータスを記録した上でXへ投稿する
- **レート制限管理**: X API Free枠（月500ツイート）を超えないよう、月間通知数を追跡し、使用率に応じて通知対象を段階的に絞り込む

## 主要なユースケース

- 障害が新規に掲載された際に、地域住民へ速報を届ける
- 障害が「復旧」「終了」「完了」などへ更新された際に、続報として状況変化を伝える
- 無人かつ低コスト（X無料枠・GitHub Actions無料枠）で継続的に運用する

## バリュープロポジション

公式ページを能動的に確認しなくても、障害の発生から復旧までのライフサイクルをXのタイムライン上で受動的に追える。誤通知・二重通知を避ける状態管理と、無料枠を守るレート制限により、追加コストや手動運用なしで継続稼働できる点が特徴。
